
# BT-CHAT - High-Quality Bluetooth Chat & Call App

**BT-CHAT** is a peer-to-peer communication app that connects devices via **Bluetooth** (Classic & BLE). It enables:
- Real-time text chat
- High-quality voice calls (HD audio)
- **Unsend** messages after they've been sent
- No internet or cellular data required

Perfect for local, offline, secure communication — camping, flights, disaster zones, or just chatting with friends nearby.

## ✨ Features

| Feature          | Description                                                                                   |
|------------------|-----------------------------------------------------------------------------------------------|
| 🔗 **BT Connect**| Pair and connect with nearby devices using Bluetooth Classic (SPP) or BLE (GATT).              |
| 💬 **Chat**      | Send/receive text messages instantly. Emoji, timestamps, delivery/read receipts optional.     |
| 📞 **HD Calling**| High-quality, low-latency voice calls using **Opus codec** over RFCOMM or custom L2CAP socket. |
| ❌ **Unsend**    | Recall any sent message (both sides) – message disappears from recipient's chat history.       |
| 🚫 **Offline**   | No internet, no SIM, no hotspot required. Works entirely over Bluetooth.                      |
| 🔒 **Privacy**   | No servers, no logs. End-to-end encryption (optional, e.g., AES-256).                         |
| 📁 **File Share**| Send images, small files (bonus feature).                                                     |

## 🚀 Getting Started

### Prerequisites
- Two (or more) Bluetooth-enabled devices:
  - Android 8.0+ (recommended) 
  - Bluetooth 4.0+ (for BLE + Classic)
- App installed on all devices.
